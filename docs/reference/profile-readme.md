## Projetos em destaque

### Arquitetura de testes de APIs

Estrutura para testes de back-end com Playwright e TypeScript, priorizando separação de responsabilidades entre *specs*, serviços, dados de teste, *fixtures*, *factories* e validações de contrato.

**Foco:** legibilidade, manutenção, isolamento, execução paralela e confiabilidade dos testes.

### Revisão de testes assistida por IA

Especificações e critérios para apoiar revisões técnicas de testes automatizados com IA, abordando duplicação, falsos positivos, *flakiness*, cobertura de cenários, qualidade de dados e aderência à arquitetura definida.

**Foco:** transformar IA em apoio prático e responsável para a engenharia de software.

### Qualidade e segurança estática com Semgrep

Estudos e materiais para análise de *rulesets* e definição de verificações voltadas a autenticação, autorização, proteção de dados, isolamento de *tenant* e padrões de qualidade de código.

**Foco:** antecipar riscos técnicos e de segurança durante o desenvolvimento.
