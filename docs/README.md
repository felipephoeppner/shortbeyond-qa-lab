## Como manter esta base útil

Quando resolver um problema recorrente, registre sintoma, causa, solução e verificação em `troubleshooting.md`. Quando mudar uma decisão de organização, atualize `architecture.md`. Quando executar um experimento de carga, registre ambiente, versão, massa, duração e resultado em uma nova evidência; não apresente uma execução local como capacidade de produção.

Prefira uma explicação com um exemplo real do projeto. Evite copiar páginas inteiras de documentação que podem ficar desatualizadas.
